# 💍 Nikhil & Isha — Wedding Celebration Invitation

A luxury, cinematic digital wedding invitation website created for the special celebration of **Nikhil & Isha**.

The invitation is designed with a premium wedding aesthetic featuring elegant typography, animated elements, countdown timer, background music, venue details, RSVP functionality, and calendar integration.

---

## ✨ Features

- 💑 Elegant animated couple illustration
- 🎂 Animated wedding cake with balloons
- ✨ Luxury cinematic wedding design
- 🕯️ Dark maroon, burgundy and antique-gold color theme
- 🎵 Background wedding music
- ⏳ Live countdown timer
- 📅 Event date and time details
- 📍 Venue details with Google Maps integration
- 💬 RSVP through WhatsApp
- 🗓️ Add event to Google/Apple/Outlook Calendar using `.ics`
- 📱 Fully responsive mobile-friendly design
- 🌟 Smooth animations and reveal effects
- 🎨 No external images required
- 🚀 Ready to deploy using GitHub Pages
